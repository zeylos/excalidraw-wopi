# Security policy

## Supported versions

The latest release receives security fixes.

## How to report a vulnerability

Report a vulnerability through a private GitHub security advisory:
<https://github.com/zeylos/excalidraw-wopi/security/advisories/new>.

Do not open a public issue for a vulnerability. Describe the problem,
the affected component, and the steps to reproduce it. You will get an
answer in the advisory thread.
